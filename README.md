# AI Service Projects

Twenty-four independently runnable Python demos based on the service catalog. Each folder is self-contained and has a dedicated README. These demonstrate focused workflows, not production deployments. No real customer data or credentials are included.

Run any demo: `cd <project> && python main.py`. Python 3.10+ required.
